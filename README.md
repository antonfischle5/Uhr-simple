# Ampel

Eine einfache Ampel-Simulation im Standard-HTML-Design.

## Dateien
- `index.html` – Seitenstruktur
- `style.css` – Ampel-Lichter
- `script.js` – automatische Ampelschaltung

## Ampelzyklus
Die Ampel schaltet automatisch in dieser Reihenfolge:

**Rot → Gelb → Grün → Gelb → Rot**

Jede Phase dauert 60 Sekunden. Die Schaltung richtet sich nach der Uhr des Geräts. Deshalb läuft sie auch nach dem Neuladen passend zur aktuellen Gerätezeit weiter.

Hinweis: Dies ist nur eine Simulation zu Lern- und Dekorationszwecken, keine echte Verkehrssteuerung.
