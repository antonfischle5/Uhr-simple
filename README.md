# Ampel-Uhr

Eine digitale Uhr mit simulierter dreifarbiger Ampel.

## Dateien
- `index.html` – Seitenstruktur
- `style.css` – Gestaltung
- `script.js` – Uhr, Ampelphasen und Einstellungen

## Start
Alle drei Dateien in denselben Ordner laden und `index.html` öffnen. Die Ampel wechselt standardmäßig alle 60 Sekunden in der Reihenfolge Rot → Gelb → Grün → Rot. Über das Zahnrad lassen sich Ampeltyp und Intervall ändern. Die Einstellungen werden lokal in diesem Browser gespeichert.

Hinweis: Dies ist nur eine Simulation zu Lern- und Dekorationszwecken, keine echte Verkehrssteuerung.
